# 使用说明

本文件是 [README](../README.md) 的详细补充：日常怎么维护、凭据过期怎么续、出问题怎么查。

---

## 一、这套东西在做什么

| 系统 | 账号 | 自动时间 |
|---|---|---|
| WorkBuddy | `<标签A>` | 每天固定时间签到一次，另每 4 小时补一次 |
| WorkBuddy | `<标签B>` | 同上，时间错开 |
| Qoder（可选） | 一个账号 | 每天固定时间一次 |

**不需要切换账号，不需要开着客户端。** 每个账号存了一份本机快照，定时任务拿着快照自己去执行，和客户端当时登录着谁完全无关。

---

## 二、为什么可以"完全不用管"

- 任务已注册为**不依赖用户登录**的方式 —— 重启后哪怕停在登录界面没登录，也会照常执行
- 任务开启**错过补跑** —— 关机或睡眠期间错过的触发，恢复后自动补执行
- 启动器用 **pythonw**，不创建控制台窗口，所以说"不会弹黑窗口"
- 锁屏、睡眠、休眠都不影响

**唯一需要人工介入的**：快照有效期约 28 天，到期前要重新登录并重抓一次（见第四节）。

**什么都不用做。**

## 四、快照过期怎么续

随时可以自查：

```bash
python check-expiry.py --live
```

输出会标注每个账号的到期日和实际连通状态：

```
account snapshots in ...\creds:
  account-a    OK    token expires 2026-11-13 00:38 (27 d) | live: OK
                    -> [OK] active=True 今日已签=True 连签=17 累计=1700
  account-b    OK    token expires 2026-11-13 00:06 (27 d) | live: OK
```

**续期三步：**

1. 在客户端登录该账号
2. 重新抓取快照：
   ```bash
   python capture-account.py <标签> --expect-phone <登录名>
   ```
   同一个标签会直接覆盖旧快照，元数据自动刷新
3. 切回你自己的常用账号（快照已固化，切走不影响）

> 如果想要自动提醒，可以配合定时任务或自动化工具，每天执行一次
> `check-expiry.py --live`，发现剩余天数 ≤ 1 天时提醒你。

## 五、添加新账号

1. 在客户端登录新账号
2. 先确认抓的是哪个账号：
   ```bash
   python capture-account.py --who
   ```
   输出里的 `who` 字段就是客户端当前登录的账号，对不上就别继续
3. 抓取快照：
   ```bash
   python capture-account.py <新标签> --expect-phone <登录名>
   ```
   `ok: true` 才算成功
4. 安装任务，`-Slot` 换一个没用过的值：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install-account.ps1 -Label <新标签> -Slot 2
   ```
5. 立即验证：
   ```powershell
   Start-ScheduledTask -TaskName WorkBuddyAutoSignin_<新标签>
   Start-Sleep 60
   Get-ScheduledTaskInfo -TaskName WorkBuddyAutoSignin_<新标签>   # 应为 0
   ```
6. 确认 `creds\<新标签>.log` 有新记录，然后切回常用账号

## 六、排错

| 现象 | 处理 |
|---|---|
| 日志出现 `AUTH_REJECTED` / 401 | 快照过期，按第四节重抓 |
| 日志出现 `MISSING_SNAPSHOT` | `creds\<标签>.info` 不存在，重新抓取 |
| 抓取时提示「忘了切账号」 | 客户端里确认显示的是目标账号再抓 |
| `check-expiry.py --live` 报 `live: ERROR` 但日志正常 | 先确认脚本为最新版；解析问题已修复 |
| 想临时停用某个账号 | `install-account.ps1 -Label <标签> -Slot <槽位> -Uninstall`（快照保留） |
| 想恢复"客户端登谁就领谁" | 运行上游的 `install-windows.ps1`（会覆盖槽位 0 的任务） |
| 屏幕上偶尔闪黑窗口 | 任务动作应为 `pythonw.exe` + `run-account.py`；若指向 `.bat`，重新执行 `install-account.ps1` |

## 七、槽位与触发时间

| 槽位 | 签到任务 | 补签任务 | 任务名 |
|---|---|---|---|
| 0 | 每天 00:05 | 每 4 小时（整点） | `WorkBuddyAutoSignin` / `WorkBuddyGrowthPoll` |
| 1 | 每天 00:35 | 每 4 小时（:35） | `WorkBuddyAutoSignin_<标签>` / `WorkBuddyGrowthPoll_<标签>` |
| 2 | 每天 00:50 | 每 4 小时（:50） | 同槽位 1 命名规则 |

槽位的作用只是**把不同账号的触发时间错开**，避免同一分钟并发。

## 八、目录结构

```
项目根目录\
├── signin.py                 签到主程序（上游，MIT）
├── run-account.py            计划任务启动器（无窗口）
├── capture-account.py        抓取账号快照 + 账号识别 + 防呆
├── install-account.ps1       安装 / 卸载某账号的两个任务
├── install-windows.ps1       上游单账号安装脚本（备用）
├── check-expiry.py           快照到期与连通性检查
├── README.md
├── docs\
│   └── 使用说明.md            本文件
└── creds\                    各账号快照 / 元数据 / 独立日志
    ├── account-a.info / .json / .log
    └── account-b.info / .json / .log
```

`creds\` 已在 `.gitignore` 中排除 —— 里面是登录凭据，**不要提交，也不要用任何方式外传**。

---

## 九、卸载

```powershell
# 逐个移除某个账号的任务（快照保留）
powershell -ExecutionPolicy Bypass -File .\install-account.ps1 -Label <标签> -Slot <槽位> -Uninstall
```

彻底清理则再删除整个 `creds\` 目录。
