# workbuddy-multi-signin

为 WorkBuddy 桌面端设计的多账号每日签到辅助工具。**多个账号并行签到，不需要来回切换客户端。**

---

## 它解决什么问题

桌面客户端同一时间只保存一个登录状态。如果你手上有多个账号都要维持每日签到，常规做法是每天挨个登录一次——麻烦，而且容易断签。

本项目把每个账号的登录状态各自固化成一个**本机快照**，让系统级定时任务分别调用它。带来的结果是：

- **不用切账号** —— 签到过程与客户端当前登录的是谁无关
- **不用开着客户端** —— 纯系统任务，客户端关闭时照常执行
- **不用先登录系统** —— 任务以「不依赖用户登录」的方式注册，重启后停在登录界面也会执行
- **不会弹窗** —— 由 pythonw 启动，全程静默无窗口

## 特性

| 能力 | 说明 |
|---|---|
| 多账号并行 | 每账号一份快照 + 一组错峰任务，互不干扰 |
| 幂等安全 | 执行前先查询当日状态，重复运行不会重复领取 |
| 免登录运行 | 计划任务不依赖用户登录，重启后自动生效 |
| 静默执行 | 不使用 .bat（会闪控制台窗口），改由 pythonw 直接执行 |
| 错过补跑 | 关机或睡眠期间错过的触发，恢复后自动补执行 |
| 凭据体检 | 可离线查看到期日，也可实测服务端连通性 |

## 环境要求

- Windows 10 / 11
- Python 3.8 或更高（建议 3.12；**不需要任何第三方库**）
- 已安装并至少登录过一次 WorkBuddy 桌面端

## 快速开始

**第 1 步 · 抓取账号快照**

先在 WorkBuddy 客户端登录目标账号，然后在项目目录执行：

```bash
python capture-account.py <标签> --expect-phone <登录名>
```

`<标签>` 自定义（例如 `account-a`），会生成 `creds\<标签>.info`、`.json`、`.log`。
脚本会校验抓到的账号是否与预期一致，对不上会拒绝写入。

**第 2 步 · 安装定时任务**

```powershell
powershell -ExecutionPolicy Bypass -File .\install-account.ps1 -Label <标签> -Slot 1
```

`-Slot` 取 `0 / 1 / 2`，对应三组错开的触发时间，多个账号各用一个槽位即可避免同时触发。

**第 3 步 · 立即验证**

```powershell
Start-ScheduledTask -TaskName WorkBuddyAutoSignin_<标签>
Start-Sleep 60
Get-ScheduledTaskInfo -TaskName WorkBuddyAutoSignin_<标签>   # LastTaskResult 应为 0
```

同时确认 `creds\<标签>.log` 出现新记录。

**第 4 步 · 平时怎么检查**

```bash
python check-expiry.py --live
```

会逐一报告每个快照的到期日和实际连通状态。

## 添加更多账号

换到下一个账号登录客户端后，重复第 1、2 步，换一个 `-Slot` 值。完成后再切回你自己常用的账号即可——**快照已经固化，切走不影响**。

## 文件说明

| 文件 | 作用 |
|---|---|
| `signin.py` | 签到主程序（来自上游项目，MIT） |
| `capture-account.py` | 把客户端当前登录状态固化为账号快照 |
| `run-account.py` | 计划任务启动器（无窗口） |
| `install-account.ps1` | 为一个账号安装 / 卸载定时任务 |
| `check-expiry.py` | 快照到期与连通性检查 |
| `install-windows.ps1` | 上游的单账号安装脚本（备用） |
| `docs/使用说明.md` | 完整操作说明 |

## 顺带：Qoder 的每日 Credits

同一台机器上如果还装着 Qoder 桌面端，可以用 [`qoder/`](qoder/) 目录下的一套东西，
按同样的思路挂到计划任务里无人值守领取 —— 同样无窗口、同样不用管。

细节见 [qoder/README.md](qoder/README.md)。

## 关于凭据

- 快照只写入本机 `creds\` 目录，**不会上传到任何地方**
- `creds\` 与各类日志已在 `.gitignore` 中排除，**请勿提交到版本库**
- 快照有效期约 28 天，到期后重新登录并重新抓取即可

## 常见问题

| 问题 | 回答 |
|---|---|
| 需要一直开着客户端吗？ | 不需要 |
| 会不会重复领取？ | 不会，执行前先查询当日状态 |
| 重启电脑要重新配置吗？ | 不需要 |
| 会不会弹黑窗口？ | 不会 |
| 换电脑怎么办？ | 在新机器上重新登录并抓取快照即可 |
